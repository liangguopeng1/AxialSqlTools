# AxialSqlTools 国际化设计

**日期：** 2026-07-22  
**状态：** 已确认，实施中

## 目标

- 默认界面语言：**中文**
- 可在 Settings 中切换：**English**
- 尽量全覆盖；工具窗口/提示尽量即时刷新；工具栏/菜单切换后提示 **重启 SSMS**
- 语言与个性配置不写注册表，统一目录见下

## 统一配置根目录

`%APPDATA%\AxialSqlTools\`（`Environment.SpecialFolder.ApplicationData`）

| 文件/目录 | 用途 |
|---|---|
| `settings.json` | 含 `uiLanguage`（`zh-CN` / `en`）等通用设置 |
| `snippets.json` | 片段（已有） |
| `data-transfer-connections.json` | Data Transfer |
| `github-sync-profiles.json` | GitHub Sync |
| `query-history\` | Query History 文件模式 |
| `templates\` | 查询模板默认目录 |
| `logs\` | 日志 |

例外：GitHub Token → Windows 凭据管理器；密码类 → DPAPI 后写入 JSON。

## 技术方案

1. `Strings.resx`（中文，默认）+ `Strings.en.resx`（英文）
2. 启动最早读取 `settings.json`，设置 `CurrentUICulture` / `DefaultThreadCurrentUICulture`
3. Settings 增加「常规」页语言下拉；保存后刷新当前设置窗，并提示菜单需重启
4. 工具栏：启动后按当前文化用 `MenuTextLocalizer` 覆盖 CommandBar 文案（VSCT 保留英文作为稳定匹配键）
5. 分批迁移其余 XAML/MessageBox（P2）
